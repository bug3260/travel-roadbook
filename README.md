# 🗺️ 路书地图 · 行程路线可视化

双击 `index.html` 即可在浏览器中打开（推荐 Edge / Chrome）。

在线访问（GitHub Pages）：https://bug3260.github.io/travel-roadbook/把文字路书变成一目了然的地图行程：景点、酒店、途经点、起终点全部上图，按天配色、真实驾车路线 + 方向箭头 + 时间标签，点击任意图标查看详情，一键导出长图分享。

## 功能

- **识别路书**：粘贴文字或拖入 `.txt / .md / .docx / .pdf`，AI 智能解析（失败自动回退内置规则），自动提取每天的地点、时间、类型。
- **生成路书**：填目的地 / 天数 / 偏好，AI 直接生成一份含时间、酒店、餐饮的行程；没有 Key 时生成空骨架 + POI 搜索手动添加。
- **地图可视化**：六类图标（起 / 景 / 途 / 宿 / 餐 / 终）+ 到达时间标签；按天配色图例；调用高德路径规划绘制沿道路的真实路线（箭头表示方向、中点标签显示交通方式 / 距离 / 用时），失败自动降级为虚线直线 + 估算时间。
- **双向联动**：侧栏按天时间轴 ↔ 地图标记；点击定位、点击编辑；可拖动图钉改坐标、地图选点、POI 搜索定位；未定位地点红色提醒。
- **保存分享**：自动存浏览器（localStorage）；导出 / 导入路书 JSON；一键导出地图长图 PNG（标题 + 地图 + 每日时间轴）。

## 首次配置（两个免费 Key，各约 5 分钟）

1. **DeepSeek（智能解析 / 生成）**
   - 到 https://platform.deepseek.com 注册并创建 API Key，打开「⚙️ 设置」填入。
   - 默认接口 `https://api.deepseek.com`、模型 `deepseek-v4-flash`；也可切换 OpenAI 或其它 OpenAI 兼容服务。
   - 不填 Key 也能用：解析走内置规则，生成走空骨架 + POI 手动添加。
2. **高德地图（地图 / 定位 / 路线）**
   - 到 https://console.amap.com 注册 →「应用管理」→「我的应用」→「创建新应用」→ 添加 Key，服务平台选 **Web端(JS API)**，得到 `Key` 与 `安全密钥(jscode)`，填入设置保存。
   - 路线规划需同一账号开通「**Web服务 API**」服务（免费配额）。
   - 白名单说明：本应用使用 JS API 1.4.15，不强制校验 Referer 白名单，白名单留空即可正常使用。如仍想填写，只能用纯域名（如 `localhost`，不带协议和端口；`file://`、`http://` 等写法会被控制台判定为非法域名）。

> 两个 Key 均只保存在本机浏览器的 localStorage，不会上传到任何服务器。更换浏览器 / 设备后需重新填写；行程数据请用「导出JSON」备份。

## 使用流程

1. 点击「📥 识别路书」→ 粘贴路书或拖入文件 →「开始解析」；或点击「✨ 生成路书」填目的地生成。
2. 解析后自动地理编码（坐标定位），侧栏时间轴与地图同步显示；点击「全程 / D1…」切换视图。
3. 编辑：悬停地点 → ✏️ 改名称 / 时间 / 交通方式 / 备注；「地图选点」或「POI搜索」修正定位；拖地图上的图钉也可以改位置。
4. 分享：点击「📷 导出长图」生成 PNG 发朋友；「导出JSON」备份 / 迁移路书。

## 地图加载失败排查

- 提示「高德 Key 未生效」：确认 Key 类型为「Web端(JS API)」、已填安全密钥(jscode)、Key 未过期或被禁用；修改后点「设置 → 保存」自动重试。本应用使用 JS API 1.4.15，不强制 Referer 白名单，白名单可留空（纯域名格式才合法，`file://` 会被拒绝，无需添加）。
- 地图空白 / 定位失败 / 没有路线：确认同一账号已开通「Web服务 API」（地理编码与路线规划需要该服务）。
- 可选：双击「启动预览.bat」以 http://localhost:8000 访问，与双击 index.html 效果相同。

## 说明与限制

- 地图、POI 搜索、路线规划需要联网；`file://` 双击打开时 PDF 解析自动使用主线程模式（已内置处理）。
- 交通方式为「公交」的段落在 v1 中用直线虚线 + 真实总时长表示。
- 长图导出使用 html2canvas；高德瓦片已确认支持跨域（`Access-Control-Allow-Origin: *`），若个别网络环境被拦截会导出文字版并提示。
- 数据模型版本 `version: 1`，字段见 `roadbook-core.js` 中 `normalizeTrip`。
